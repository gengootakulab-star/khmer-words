# クメール語 単語分解ツール

クメール語(カンボジア語)の単語を入力すると、文字の組み立て(子音・足(コーン)・母音記号・末子音など)に分けて表示するツールです。

**▶ ツールを使う:** https://gengootakulab-star.github.io/khmer-words/

「言語オタクの多言語学習ラボ」で公開しているツールの一つです。
サイト: https://gengootakulab-star.github.io/

## できること

- 単語を入力すると、文字のパーツごとに分けて表示します
- 子音が **a系列** か **o系列** かを示します(同じ母音記号でも、系列によって読み方が変わります)
- 読みの目安を発音記号(IPA)で表示します(規則から作った目安です)
- 収録している単語には意味を表示します(Wiktionary の英語の意味と、一部の単語は日本語の意味も)

## 使い方

1. 入力欄にクメール語の単語を入れます(コピー&ペーストでも大丈夫です)。クメール語は単語の間に空白を入れないので、1語ずつ入力してください
2. 分解されたパーツが表示されます
3. 気になるパーツをタップして、説明を読みます

## データについて

- 単語データと英語の意味は [Wiktionary](https://en.wiktionary.org/) をもとにしています。データは [kaikki.org](https://kaikki.org/) で公開されているものを使いました
- Wiktionary の内容は [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja) で公開されています。このツールに入っている単語データも、同じ CC BY-SA 4.0 の条件で使えます
- 日本語の意味(約80語)は、運営者がAIの助けを借りて付けたものです

## ご注意

- 個人が趣味で作っている学習用のツールです。分解の結果・読み・意味に誤りが含まれている可能性があります。読みは実際の発音や音節の区切りと違うことがあります
- 正確さが必要なときは、辞書や先生など、ほかの情報源もあわせて確認してください
